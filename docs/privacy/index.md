# Notevine (Android) 개인정보처리방침

시행일: 2026-11-14

Notevine은 휴대폰 안의 마크다운 노트를 쓰고 찾는 앱입니다. 개발자는 사용자의 노트나 개인정보를 수집하거나 개발자 서버로 보내지 않으며, 개발자가 운영하는 서버도 없습니다.

## 1. 수집하는 정보
없음. 앱에는 회원가입·로그인, 광고, 사용 통계, 오류 수집 도구가 없습니다.

## 2. 기기에 저장되는 정보
다음은 모두 사용자의 휴대폰 안, 이 앱만 접근할 수 있는 저장 공간에 있습니다.
- 노트 폴더의 노트(마크다운 파일), 첨부 파일, 앱 설정.
- 동기화를 설정한 경우 GitHub 접근 토큰과 암호화 백업 복구 코드. Android Keystore(꺼낼 수 없는 열쇠)로 잠가서 저장하며, 동기화 대상이 아닙니다.
- 앱 잠금을 쓰는 경우 앱 비밀번호의 해시(솔트 포함). 생체인증 정보는 Android 시스템이 관리하며 앱은 받지 않습니다.

앱을 지우거나 앱 저장 공간을 비우면 위 정보가 모두 삭제됩니다. 노트 폴더는 앱 안에서 "파일까지 삭제"로 지울 수도 있습니다.

## 3. 외부로 전송되는 정보
사용자가 설정 화면에서 GitHub 동기화를 직접 설정하고 실행한 경우에만, 해당 노트 폴더의 노트와 첨부 파일이 사용자가 지정한 GitHub 저장소로 전송됩니다(GitHub API, `api.github.com`). 이 전송에는 사용자가 입력한 접근 토큰이 쓰입니다. 전송된 데이터는 GitHub의 약관과 개인정보 정책을 따르며, 개발자는 접근할 수 없습니다. 암호화 백업을 쓰면 노트는 암호화된 상태로 전송됩니다. 동기화를 설정하지 않으면 아무것도 전송되지 않습니다.

## 4. 앱이 쓰는 권한
- 인터넷: GitHub 동기화에만 사용합니다.
- 생체인증(선택): 앱 잠금에만 사용합니다.

## 5. 아동
이 앱은 특정 연령을 대상으로 개인정보를 수집하지 않습니다.

# Notevine (Android) Privacy Policy

Effective: 2026-11-14

Notevine is an app for writing and finding Markdown notes on your phone. The developer does not collect your notes or personal information and does not send them to any developer-operated server (there is none).

## 1. Information collected
None. The app has no sign-up or login, ads, analytics, or crash reporting.

## 2. Information stored on your device
All of the following stays on your phone in storage that only this app can access.
- Notes (Markdown files), attachments and settings in your note folders.
- If you set up sync: your GitHub access token and the recovery code for encrypted backups, locked with the Android Keystore (a key that cannot be extracted). They are never synced.
- If you use app lock: a salted hash of the app password. Biometric data is handled by Android; the app never receives it.

Uninstalling the app or clearing its storage deletes all of this. You can also delete a note folder inside the app with "Delete the files too".

## 3. Information sent elsewhere
Only if you set up GitHub sync yourself and run it, the notes and attachments of that note folder are sent to the GitHub repository you chose (GitHub API, `api.github.com`), using the access token you entered. That data is subject to GitHub's terms and privacy policy, and the developer cannot access it. With encrypted backup, notes are sent encrypted. If you do not set up sync, nothing is sent.

## 4. Permissions
- Internet: used only for GitHub sync.
- Biometrics (optional): used only for app lock.

## 5. Children
The app does not collect personal information from anyone, including children.
