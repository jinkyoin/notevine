## 2. 성능 (NFR-PRF-01~05)

`scripts/gen-test-vault.mjs`로 만든 노트 1만 개(21.9MB, 한글 본문 1~3KB, 속성·태그·링크 포함)와 1MB 노트로 `tests/e2e/perf.cjs`를 실행했다.

| ID | 항목 | 결과 | 기준 | 판정 |
| --- | --- | --- | --- | --- |
| NFR-PRF-01 | 시작 (인덱스 있음, 마지막 노트 폴더 자동 열기) | 1.6~2.1초 | 3초 | 통과 |
| NFR-PRF-02 | 전문 검색 20개 평균 | 55~68ms (최대 103ms) | 200ms | 통과 |
| NFR-PRF-03 | 최초 인덱싱 1만 개 | 5.9초 (파일 캐시됨) / 29.4초 (파일을 막 만든 직후) | 60초 | 통과 |
| NFR-PRF-04 | 1MB 노트 입력 지연 (중앙값) | 15ms (작은 노트와 같음) | 50ms | 통과 |
| NFR-PRF-04 | 빈 줄 없는 1MB 한 문단 입력 지연 | 53~61ms | 50ms | 극단 사례, 약간 초과 |
| NFR-PRF-05 | 설치 파일 크기 | setup.exe 3.3MB / MSI 4.4MB | 30MB | 통과 |
| NFR-PRF-05 | 유휴 메모리 (전용 메모리) | 앱 17MB + WebView2 280~420MB | 500MB (WebView2 포함) | 통과 |

**측정 중 고친 것**

- 최초 인덱싱이 120.9초 → 5.9초: 노트마다 하던 DB 커밋을 500개 단위로 묶고, 파일 읽기·분석을 병렬로 바꿨다.
- 1MB 노트 입력 지연 57ms → 15ms: frontmatter 접기가 키를 누를 때마다 문서 전체를 복사하던 것을 없앴다.

**메모리 기준 (2026-10-30 결정)**

노트 1개짜리 노트 폴더에서도 전용 메모리 합계가 216MB다(WebView2 약 208MB, 앱 8MB). WebView2를 포함한 처음 기준(200MB)은 이 구조로는 맞출 수 없어서, 기준을 "WebView2 포함 500MB 이하"로 바꿨다. 측정값 최대 약 437MB(앱 17MB + WebView2 420MB)로 통과한다.

## 3. AI 실사용 테스트 (NFR-USA-01)

개발계획서 6.3의 방법대로, 코드와 문서를 보지 않은 AI 에이전트 3개가 각자 따로 띄운 릴리스 앱을 화면(스크린샷)과 마우스·키보드만으로 조작했다. OS 폴더 선택 창은 자동 조작이 안 되므로, 빈 폴더를 노트 폴더로 미리 열어 둔 상태에서 시작했다.

| 과제 | 테스터 1 | 테스터 2 | 테스터 3 |
| --- | --- | --- | --- |
| ① 첫 노트 만들고 쓰기 | 성공 · 4회 | 성공 · 5회 | 성공 · 6회 |
| ② 오늘 업무일지 쓰기 | 성공 · 9회 (2번 헤맴) | 성공 · 10회 (2번 헤맴) | 성공 · 7회 |
| ③ 아이디어 빠른 메모 | 성공 · 4회 | 성공 · 4회 | 성공 · 4회 |
| ④ 노트 검색해서 열기 | 성공 · 3회 | 성공 · 3회 | 성공 · 3회 |
| ⑤ 고친 뒤 이전 내용으로 되돌리기 | 부분 · 8회 | 부분 · 11회 | 부분 · 8회 |

NFR-USA-01 기준(막힌 지점 0, 조작 10회 이내)으로 과제 ①은 3회 모두 통과했다. 과제 ②는 헤맨 지점이 있었고, 과제 ⑤는 히스토리로 되돌리지 못하고 Ctrl+Z로 되돌렸다.

### 3.3 v0.1에서 고치지 않은 것

- 속성 이름·값이 영어 그대로 보임(`type: journal`). 속성은 사용자 데이터라 바꾸지 않았고, 표시용 한국어 이름은 v0.2에서 검토한다.
- "노트 폴더"라는 용어 자체. → 2026-10-30에 화면·문서 모두 "노트 폴더"로 바꿨다.
- 편집 전에도 "√ 저장됨"이 보여 저장 여부가 헷갈린다는 지적(2/3).
- 실행 취소(Ctrl+Z)가 화면에 안내되지 않음.

## 4. 직접 확인하지 못한 것

자동화로 재현할 수 없어 사람이 확인해야 한다.

- 파일 트리에서 실제 마우스로 끌어 옮기기, 탐색기에서 앱으로 파일 끌어다 놓기
- 첨부 파일을 OS 기본 프로그램(엑셀 등)으로 열기
- Windows 한글 입력기(IME)로 직접 타이핑 (자동 테스트는 조합 이벤트를 흉내 냄)
- 설치 파일(MSI·setup.exe)로 설치·제거, SmartScreen 경고 문구
- GitHub Actions CI 통과 여부 (비공개 저장소라 확인 권한이 없었음)
