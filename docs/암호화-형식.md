# Git 백업 암호화 형식

Notevine이 Git 백업에 올리는 파일을 암호화하는 형식이다. 데스크톱(`src-tauri/src/crypt.rs`)과
이후 모바일 앱이 같은 형식을 써야 하므로 바이트 단위로 고정한다.

**모바일 구현은 `src-tauri/testdata/crypt-vectors.json`의 시험 자료를 통과해야 한다.**
(주 열쇠 `00..1f`, 평문 3개. 모든 hex는 소문자.)

| 항목 | 값 |
| --- | --- |
| 알고리즘 | AES-256-SIV (RFC 5297), 결정적 암호화(같은 열쇠·같은 평문 → 같은 출력) |
| 주 열쇠 | 무작위 32바이트 |
| SIV 열쇠 64바이트 | HKDF-SHA256(ikm=주 열쇠, salt=`"notevine-crypt-v1"`, info=`"aes-siv-256"`) |
| 열쇠 식별값 | HKDF-SHA256(같은 ikm·salt, info=`"key-id"`) 8바이트 → 소문자 hex 16자 |
| 파일 | `b"NVENC"` + 버전 `0x01` + 열쇠 식별값 8바이트(원시) + SIV 출력(16바이트 태그 + 암호문) |
| SIV 연관 데이터 | 앞의 14바이트 머리(`NVENC`·버전·식별값) 하나 |
| 복구 코드 | 주 열쇠 32바이트 + SHA-256(주 열쇠) 첫 2바이트(34바이트)를 Crockford Base32(대문자, 알파벳 `0123456789ABCDEFGHJKMNPQRSTVWXYZ`)로 쓰고, 마지막 글자는 0 비트로 채우며, 6자마다 `-` |
| 복구 코드 읽기 | 대소문자·공백·`-` 무시, `O`→`0`, `I`·`L`→`1`. 길이·남는 비트·검사값이 맞지 않으면 거부 |
| `.notevine-crypt` | 저장소 루트의 평문 파일. JSON `{"format":1,"key_id":"<hex>"}` + `\n` |

복호화는 머리(매직·버전)를 확인하고, 식별값이 현재 열쇠와 다르면 "다른 열쇠"로, 태그가
맞지 않으면 변조·손상으로 거부한다.
