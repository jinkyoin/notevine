# Notevine

내 컴퓨터의 마크다운 폴더에 업무 기록·아이디어·조사 자료를 쓰고, 링크로 연결하고, 검색과 히스토리로 다시 찾는 데스크톱 앱입니다.

- 노트는 표준 `.md` 파일로만 저장합니다. 다른 편집기로 열어도 그대로입니다.
- 모든 저장 시점이 히스토리에 남아, 언제든 비교하고 되돌릴 수 있습니다.
- 외부 서버로 아무것도 보내지 않습니다. 계정도 필요 없습니다.
- MIT 라이선스 오픈소스입니다.

> **v0.1은 Windows 10 이상만 지원합니다.** macOS·Linux는 v0.2 이후에 지원할 예정입니다.

## 설치

[Releases](../../releases)에서 `Notevine_x.y.z_x64_ko-KR.msi` 또는 `Notevine_x.y.z_x64-setup.exe`를 받아 실행합니다.

코드 서명이 없어서 Windows SmartScreen 경고("Windows의 PC 보호")가 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 설치됩니다.

## 무엇을 할 수 있나요

| 기능 | 사용법 |
| --- | --- |
| 볼트 | 아무 폴더나 볼트로 엽니다. 다음 실행 때 마지막 볼트와 노트가 다시 열립니다 |
| 편집기 | 커서가 없는 줄은 서식으로 보이는 라이브 미리보기, 1초 자동 저장, 코드 블록 문법 강조 |
| 링크 | `[[` 입력 시 노트 자동완성, Ctrl+클릭으로 이동, 없는 노트는 만들어서 열기, 백링크 패널 |
| 이름 변경 | 노트·폴더 이름을 바꾸거나 옮기면, 가리키는 링크를 미리 보여 주고 함께 고칩니다 |
| 검색 | 한글 두 글자로도 부분 일치. `#태그` `status:검토` `type!=idea` `"정확한 구"`, 기간 필터 |
| 속성 | 노트 맨 위 YAML(frontmatter)을 속성 패널에서 날짜·목록·URL 등 유형별로 편집 |
| 히스토리 | 저장할 때마다 버전이 쌓이고(5분 단위로 묶음), 줄 단위 비교와 복원, 삭제한 노트 되살리기 |
| 외부 변경 | 다른 프로그램이 노트를 고치면 바로 반영되고, 동시에 고친 경우 양쪽 내용을 모두 보존합니다 |
| 첨부 | 파일을 끌어다 놓거나 이미지를 붙여넣으면 `첨부/`에 저장하고 링크를 넣습니다. 이미지는 미리보기 |
| 기록 관리 프리셋 | 업무일지·아이디어·조사자료 폴더와 템플릿 4종, 오늘 업무일지, 빠른 메모, 아이디어 보드 |

### 단축키

| 단축키 | 동작 |
| --- | --- |
| Ctrl+O | 빠른 열기 |
| Ctrl+P | 명령 팔레트 |
| Ctrl+N | 새 노트 (템플릿 선택) |
| Ctrl+Shift+N | 빠른 메모 |
| Ctrl+Shift+D | 오늘 업무일지 |
| Ctrl+Shift+F | 검색 |
| Ctrl+S | 저장 (히스토리 버전으로 남김) |
| Ctrl+\\ / Ctrl+Shift+\\ | 왼쪽 사이드바 / 오른쪽 패널 접기 |
| Ctrl+, | 설정 |
| F2 | 현재 노트 이름 변경 |
| Alt+← / Alt+→ | 이전 / 다음 노트 |

## 볼트 구조

```
내 볼트/
├─ *.md            # 노트 (유일한 원본)
├─ 첨부/            # 이미지·파일
└─ .app/
   ├─ config.json     # 볼트 설정
   ├─ workspace.json  # 마지막으로 연 노트
   ├─ index.db        # 검색 인덱스 (지워도 다시 만들어짐)
   └─ history.db      # 변경 이력 (다시 만들 수 없음)
```

**`.app/history.db`는 다시 만들 수 없으니 볼트와 함께 백업하세요.** `index.db`는 지워도 다음 실행 때 다시 만들어집니다.

## 개발

필요한 것: Windows 11, [Rust](https://rustup.rs), Node.js 22 이상, Visual Studio Build Tools(C++ 데스크톱 개발), WebView2(Windows 11 기본 포함)

```bash
npm install
npm run tauri dev      # 개발 실행
npm test               # 프론트엔드 단위 테스트 (Vitest)
cargo test --manifest-path src-tauri/Cargo.toml   # 백엔드 단위 테스트
npm run tauri build    # 설치 파일 만들기 → src-tauri/target/release/bundle/
```

화면 자동 테스트와 성능 측정은 [`tests/e2e/README.md`](tests/e2e/README.md)를 보세요.

설계 문서는 [`docs/`](docs)에 있습니다: 개발계획서, 요구사항정의서, 화면설계서.
기여 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)를 보세요.
