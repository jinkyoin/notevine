# Notevine

내 컴퓨터의 마크다운 폴더에 업무 기록·아이디어·조사 자료를 쓰고, 링크로 연결하고, 검색과 히스토리로 다시 찾는 데스크톱 앱입니다.

- 노트는 표준 `.md` 파일로만 저장합니다. 다른 편집기로 열어도 그대로입니다.
- 모든 저장 시점이 히스토리에 남아, 언제든 비교하고 되돌릴 수 있습니다.
- 외부 서버로 아무것도 보내지 않습니다. 계정도 필요 없습니다. (직접 켠 AI 도우미에서 보내기를 확인한 내용만 예외)
- MIT 라이선스 오픈소스입니다.

> **v0.1은 Windows 10 이상만 지원합니다.** macOS·Linux는 v0.2 이후에 지원할 예정입니다.

## 설치

1. [Releases](../../releases)에서 최신 버전의 `Notevine_x.y.z_x64-setup.exe`를 받습니다. 회사 PC처럼 MSI 설치가 필요하면 `Notevine_x.y.z_x64_ko-KR.msi`를 받습니다.
2. 받은 파일을 실행합니다. 설치 프로그램이 Windows 경고창을 띄우면 아래 안내를 따릅니다.
3. 설치가 끝나면 Notevine을 실행하고, 노트로 쓸 폴더를 열거나 새로 만듭니다.

Windows 10에서 WebView2가 없으면 설치 중에 자동으로 받으므로 인터넷 연결이 필요합니다.

### "Windows의 PC 보호" 경고가 뜨면

Notevine은 아직 코드 서명 인증서가 없어서 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보**를 누른 뒤 **실행**을 누르면 설치됩니다.

이 경고는 프로그램이 위험하다고 판정했다는 뜻이 아니라, Windows가 아직 잘 모르는 프로그램이라는 뜻입니다. 그래도 설치 파일은 이 저장소의 [Releases](../../releases)에서만 받으세요. 다른 곳에서 받은 파일이면 실행하지 마세요.

### 업데이트

설정 → 정보 → **지금 확인**을 누르면 새 버전을 확인합니다. 새 버전이 있으면 설치할지 묻고, 서명을 확인한 파일만 설치한 뒤 다시 시작합니다. **시작할 때 확인**을 켜면 앱을 시작할 때마다 확인합니다. 기본은 꺼져 있어서, 누르거나 켜기 전에는 인터넷에 접속하지 않습니다.

### 제거

Windows 설정 → 앱 → 설치된 앱에서 Notevine을 제거합니다. 노트와 히스토리는 노트 폴더에 있으므로 함께 지워지지 않습니다. 제거 창에 앱 데이터를 지우는 항목이 보이면, 최근 폴더 목록과 허용 설정을 남기려면 체크하지 마세요. Google Drive·OneDrive 폴더를 쓴다면 그 히스토리는 앱 데이터에 있어 이 항목을 체크하면 함께 지워집니다(노트는 지워지지 않습니다).

| 기록 관리 프리셋 | 업무일지·아이디어·조사자료 폴더와 템플릿 4종, 오늘 업무일지, 빠른 메모, 아이디어 보드 |
| AI 도우미 | PC에 로그인된 **Claude Code**·**Codex CLI**로 노트에 질문(출처 링크), 글 요약·다듬기·이어 쓰기·번역, 주간 회고 초안. 질문 하나로 내 노트와 웹을 함께 찾아보고 출처 링크를 단 답을 새 노트로 저장. 기본은 꺼져 있고, 보낼 노트를 매번 보여 주고 확인한 것만 보냅니다. `#비공개` 태그가 붙은 노트는 절대 보내지 않습니다 |

## 볼트 구조

볼트는 노트를 담는 폴더 하나입니다. 다른 폴더로 바꾸려면 화면 왼쪽 위의 **볼트 이름 ▾ → 볼트 바꾸기**를 누르고, 시작 화면에서 폴더를 고르거나 최근 볼트를 누릅니다(명령 팔레트 Ctrl+P → "볼트 바꾸기"도 같음).

```
내 볼트/
├─ *.md            # 노트 (유일한 원본)
├─ 첨부/            # 이미지·파일
└─ .app/
   ├─ config.json     # 볼트 설정
   ├─ workspace.json  # 마지막으로 연 노트
   ├─ index.db        # 검색 인덱스 (지워도 다시 만들어짐)
   └─ history.db      # 변경 이력 (다시 만들 수 없음)
```

**`.app/history.db`는 다시 만들 수 없으니 볼트와 함께 백업하세요.** `index.db`는 지워도 다음 실행 때 다시 만들어집니다.

## 개발

필요한 것: Windows 11, [Rust](https://rustup.rs), Node.js 22 이상, Visual Studio Build Tools(C++ 데스크톱 개발), WebView2(Windows 11 기본 포함)

```bash
npm install
npm run tauri dev      # 개발 실행
npm test               # 프론트엔드 단위 테스트 (Vitest)
cargo test --manifest-path src-tauri/Cargo.toml   # 백엔드 단위 테스트
npm run tauri build    # 설치 파일 만들기 → src-tauri/target/release/bundle/
```

화면 자동 테스트와 성능 측정은 [`tests/e2e/README.md`](tests/e2e/README.md)를 보세요.

설계 문서는 [`docs/`](docs)에 있습니다: 개발계획서, 요구사항정의서, 화면설계서.
기여 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)를 보세요.

## AI 도우미 쓰기

1. [Claude Code](https://claude.com/claude-code)(Claude Pro/Max) 또는 [Codex CLI](https://github.com/openai/codex)(ChatGPT)를 설치합니다. 로그인되어 있지 않으면 AI 패널이나 설정 → AI의 **로그인** 버튼을 누르세요. 각 CLI의 공식 로그인 창이 열리고, 브라우저에서 로그인을 마치면 자동으로 연결됩니다.
2. Notevine 설정 → AI에서 AI 도우미를 켭니다. 설치된 CLI를 자동으로 찾습니다.
3. 오른쪽 패널 AI 도우미(Ctrl+J)에서 질문하거나, 명령 팔레트에서 "AI: 요약" 등을 실행합니다.
4. 질문하면 관련 노트를 함께 보내고, 노트로 부족하면 AI가 웹에서도 찾아봅니다(보내기 확인 창의 **웹에서도 찾아보기**로 끌 수 있음). 답은 **새 노트로 저장**으로 남깁니다.

Notevine은 CLI의 로그인 정보를 읽지 않고 공식 CLI를 실행만 합니다. CLI는 빈 임시 폴더에서 도구 없이 실행되어 노트 파일에 손대지 않습니다. '웹에서도 찾아보기'를 켠 질문에만 웹 검색·페이지 읽기 도구를 허용합니다(그 외 도구는 계속 막힘).
